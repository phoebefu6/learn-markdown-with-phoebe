# learn markdown with phoebe

Interactive courseware: markdown for total beginners, in four 45-minute sessions - nothing to install, and your own page live on GitHub by the end.

**Live site:** https://phoebefu6.github.io/learn-markdown-with-phoebe/

## The course

| # | Session | You walk out with |
|---|---------|-------------------|
| 1 | First words | The markdown mental model + your about-me page drafted in a split-pane editor |
| 2 | Structure | A photo, a quote block, a skills table, and a checklist on your page |
| 3 | Polish | Badges, emoji, collapsibles, a Mermaid diagram, and a mini TOC |
| 4 | Ship it | Your page LIVE on your GitHub profile |

Plus a self-paced deep-dive track: markdown for AI work, flavors + export (pandoc, static sites), and Mermaid beyond basics.

Static HTML - no build step:

```
python3 -m http.server 8000
```
